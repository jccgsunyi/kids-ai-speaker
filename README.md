# 儿童AI智能音箱对话系统

专为3-4岁儿童设计的AI语音对话系统，基于小米音箱+MiGPT实现。

## 功能特点

- 🌟 **儿童友好人设**：温柔的"小星星"AI伙伴
- 🛡️ **安全过滤**：双向内容过滤，保护儿童免受不当内容
- 👨‍👩‍👧 **家长监控**：Web面板查看对话记录和安全事件
- 📚 **丰富内容**：故事、儿歌、谜语、学习内容
- 🎤 **连续对话**：支持自然的多轮对话
- 💰 **零成本**：使用免费大模型API

## 快速开始

### 1. 准备工作

**硬件要求**：
- 小米/小爱智能音箱（推荐：小爱音箱Pro）
- 威联通NAS或其他Docker环境

**账号准备**：
- 小米账号（记住小米ID和密码）
- 硅基流动账号（免费2000万tokens）：https://cloud.siliconflow.cn

### 2. 下载配置

```bash
# 克隆项目
git clone https://github.com/jccgsunyi/kids-ai-speaker.git
cd kids-ai-speaker

# 复制配置文件
cp config/.env.example config/.env
cp config/.migpt.example.js config/.migpt.js
```

### 3. 修改配置

**编辑 `config/.env`**：
```env
# 硅基流动API密钥
ACTUAL_LLM_API_KEY=sk-你的密钥

# 家长监控密码（请修改）
MONITOR_PASSWORD=你的密码
```

**编辑 `config/.migpt.js`**：
```javascript
speaker: {
  userId: "你的小米ID",     // 数字ID，非手机号
  password: "你的密码",
  did: "小爱音箱Pro",       // 与米家APP完全一致
}
```

### 4. 启动服务

```bash
# 创建必要目录
mkdir -p logs data

# 启动所有服务
docker-compose up -d

# 查看日志
docker logs -f kids-ai-speaker
```

### 5. 测试使用

对音箱说：
> "小爱同学，**请问**小星星是谁？"

进入连续对话模式：
> "小爱同学，**召唤小星星**"
